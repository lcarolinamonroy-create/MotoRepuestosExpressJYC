Análisis de Interfaz Gráfica

Documentación de maquetación para: Motorepuestos Express

1. Estructura General (Layout)

Enfoque Semántico: La interfaz está pensada para ser maquetada utilizando HTML5. Esto permite que el código sea comprensible tanto para los desarrolladores como para los navegadores.

El diseño gráfico del aplicativo se traduce en las siguientes áreas principales de código:

  • <header>: Ubicado en la parte superior. Contiene el logotipo del proyecto y la barra de navegación principal (para ir al inicio, catálogo, contacto, etc.).
  • <main>: Es el contenedor central y más importante. Aquí cambia el contenido dinámicamente según lo que el usuario esté buscando.
  • <aside>: Un panel lateral opcional, ideal para colocar filtros de búsqueda (ej. buscar repuestos por marca, cilindraje o precio).
  • <footer>: El pie de página con información de contacto, enlaces a redes sociales y derechos de autor.

2. Lógica del Módulo de Accesorios

Basado en los recursos gráficos (como el archivo accesorios.png analizado anteriormente), la sección del catálogo de productos sigue un diseño basado en "Grid" (cuadrícula) utilizando tarjetas (Cards).

Estructura de una "Tarjeta de Producto" (Card)

Para cada ítem en la tienda (por ejemplo, chaquetas reflectivas, guantes, cascos), el HTML sugerido dentro de la sección principal sería un <article> o un <div class="card"> que debe contener:

  1. Contenedor de Imagen: Una etiqueta <img src="ux/accesorios.png"> que carga el gráfico correspondiente al producto.
  2. Título del Producto: Un <h3> con el nombre exacto del artículo.
  3. Precio: Una etiqueta <p class="precio"> destacando el valor.
  4. Botón de Acción: Un botón <button>Agregar al Carrito</button> para interactuar con la compra.

3. Flujo de Navegación (UX)

La lógica visual dicta cómo interactúa el usuario con la plataforma:

  • Inicio: El usuario es recibido con banners promocionales de repuestos destacados.
  • Exploración: Al hacer clic en una categoría (ej. "Accesorios"), el sistema oculta el contenido anterior y carga los productos correspondientes en el <main>.
  • Interactividad: Las imágenes (como las PNG) están optimizadas para cargarse rápido y proporcionar una representación visual clara antes de la decisión de compra.
