# Moto Repuestos Express JYC

Módulo front-end académico para consultar y comprar repuestos y accesorios para motocicletas.

## Tecnologías

- React
- JavaScript y JSX
- React Router
- CSS
- Vite

## Funcionalidades desarrolladas

- Página de inicio con categorías y promociones.
- Catálogo filtrado por categoría.
- Tarjetas reutilizables de productos.
- Carrito de compras con `localStorage`.
- Promociones.
- Inicio de sesión, registro y recuperación de contraseña como demostración front-end.
- Navegación entre pantallas.

## Ejecución local

```bash
npm install
npm run dev
```

## Organización

- `src/components`: piezas reutilizables de la interfaz.
- `src/pages`: pantallas completas.
- `src/context`: estado compartido del carrito.
- `src/data.js`: productos temporales del prototipo.
- `public/IMG`: imágenes del proyecto.

La conexión con una API, base de datos, autenticación segura e inventario en tiempo real queda como una etapa posterior.
