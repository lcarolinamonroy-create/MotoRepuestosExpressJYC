# Moto Repuestos Express JYC

Proyecto front-end académico para consultar repuestos y accesorios para motocicletas.

## Ejecutar

1. Abrir la carpeta `HTML`.
2. Ejecutar `index.html` en un navegador, preferiblemente mediante Live Server.
3. Probar las categorías, promociones, carrito, registro, inicio de sesión y recuperación.

## Funcionalidades

- Catálogo por categorías.
- Productos con precios y fotografías.
- Carrito persistente mediante `localStorage`.
- Eliminación individual y vaciado del carrito.
- Promociones que agregan productos al carrito.
- Registro e inicio de sesión local para demostración front-end.
- Formulario de pedido simulado sin almacenar datos bancarios.

## Nota técnica

La autenticación y el pedido funcionan únicamente en el navegador para fines académicos. Para producción se requiere un backend, base de datos, autenticación segura y una pasarela de pagos autorizada.
